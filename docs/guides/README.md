# Reference guidance for the AI plan

Every `.md` file in this folder (except this README) is added to the Gemini plan prompt as reference guidance, in file-name order, cut at 6,000 characters in total.

Use it for general Canadian rules the plan can rely on, such as EI basics, asking a lender for a payment deferral, or emergency-fund rules of thumb. Each fact should cite its source (for example a Canada.ca or FCAC page) and the date checked, because rules and amounts change.

This folder is empty until sourced guidance is added. The AI is told not to state benefit amounts or eligibility rules that are not in this guidance or the customer's text.
